#### 1.1 注册流程（代码级）

```java
@Transactional
public LoginVO register(RegisterDTO dto) {
    // 1️⃣ 从Redis验证短信验证码（key="sms:register:手机号"）
    smsCodeUtil.verifyCode(redisTemplate, "register", dto.getPhone(), dto.getSmsCode());

    // 2️⃣ 校验手机号唯一性
    User existUser = userMapper.selectByPhone(dto.getPhone());
    if (existUser != null) throw BizException(PHONE_ALREADY_REGISTERED);

    // 3️⃣ BCrypt加密密码 → 创建用户
    user.setPassword(passwordEncoder.encode(dto.getPassword()));
    user.setStatus(Constants.USER_ENABLED); // 启用
    userMapper.insert(user);

    // 4️⃣ 分配默认角色 ROLE_FARMER（role_id=1）
    UserRole userRole = new UserRole();
    userRole.setUserId(user.getId());
    userRole.setRoleId(1);
    userRoleMapper.insert(userRole);

    // 5️⃣ 生成双Token
    String accessToken = jwtUtil.generateAccessToken(user.getId(), user.getUsername());
    String refreshTokenId = generateAndSaveRefreshToken(user.getId());

    // 6️⃣ accessToken存入Redis（用于登出时失效）
    redisTemplate.opsForValue().set("user_token:" + userId, accessToken, 24, HOURS);

    return LoginVO(accessToken, refreshTokenId, roles...);
}
```

#### 1.2 双Token机制

| Token | 有效期 | 存储位置 | 用途 |
|-------|--------|---------|------|
| Access Token | 2小时 | 客户端内存/Storage | 每次请求携带，鉴权 |
| Refresh Token | 30天 | Redis主 + PostgreSQL备 | 静默刷新Access Token |

**Access Token Payload:**
```json
{
  "sub": "12345",
  "role": "ROLE_FARMER",
  "orchard_ids": [1, 2, 3],
  "iat": 1716268800,
  "exp": 1716272400
}
```

**Refresh Token存储策略：**
```
tokenId = "rt_" + UUID(16位)
Redis:  "refresh_token:{tokenId}" → userId (30天TTL)
DB:     sys_refresh_token 表 (id, user_id, token_id, expires_at, revoked, created_at)
登出时: 标记数据库 revoked=true + 删除Redis
```

#### 1.3 微信一键登录（最复杂流程）

```java
@Transactional
public LoginVO loginByWechatPhone(WechatPhoneLoginDTO dto) {
    // 1️⃣ 调用微信API获取session_key + openid
    //    GET https://api.weixin.qq.com/sns/jscode2session
    //       ?appid={appId}&secret={secret}&js_code={code}&grant_type=authorization_code
    JsonNode wxResult = getWechatSession(dto.getCode());
    String openid = wxResult.get("openid").asText();
    String sessionKey = wxResult.get("session_key").asText();

    // 2️⃣ AES-128-CBC解密手机号
    //    使用 sessionKey + encryptedData + iv → AES/CBC/PKCS5Padding解密
    //    解密出 {"phoneNumber":"138xxx","purePhoneNumber":"138xxx","countryCode":"86"}
    String phone = WechatPhoneUtil.decryptPhoneNumber(sessionKey,
                    dto.getEncryptedData(), dto.getIv());

    // 3️⃣ 查用户是否存在
    User user = userMapper.selectByPhone(phone);
    if (user != null) {
        // ✅ 老用户 → 校验状态 → 生成Token → 返回(isNewUser=false)
        return LoginVO.builder().isNewUser(false).build();
    }

    // 🆕 新用户 → 自动注册（随机密码）
    user = new User();
    user.setPhone(phone);
    user.setUsername("微信用户" + phone.substring(phone.length() - 4));
    user.setPassword(passwordEncoder.encode(UUID.randomUUID().toString()));
    user.setStatus(Constants.USER_ENABLED);
    userMapper.insert(user);
    userRoleMapper.insert(new UserRole(user.getId(), 1));
    return LoginVO.builder().isNewUser(true).build();
}
```

#### 1.4 JWT过滤器 — 请求鉴权全过程

```
请求到达
   │
   ▼
① 从Header提取 "Authorization: Bearer {token}"
   │
   ▼
② JJWT校验签名 + 有效期
   jwtUtil.validateToken(token):
     Jwts.parser().verifyWith(Keys.hmacShaKeyFor(secretBytes))
         .build().parseSignedClaims(token).getPayload()
   │
   ▼
③ 从JWT claims解析：userId, username
   │
   ▼
④ Redis双检 — 这个token是否被登出失效？
   redis.get("user_token:" + userId) == token ?
   │
   ▼
⑤ 从DB加载角色权限 → List<SimpleGrantedAuthority>
   │
   ▼
⑥ 创建UsernamePasswordAuthenticationToken → 设置SecurityContextHolder
   │
   ▼
⑦ 放行到下一个过滤器 / Controller
```

#### 1.5 Spring Security配置

```java
@Configuration
@EnableWebSecurity
@EnableMethodSecurity  // 开启 @PreAuthorize 注解
public class SecurityConfig {
    // 白名单路径
    private static final String[] WHITE_LIST = {
        "/api/auth/register", "/api/auth/login/**", "/api/auth/refresh", "/api/auth/sms/**",
        "/api/device/**", "/api/images/proxy/**",
        "/doc.html", "/swagger-ui/**", "/swagger-ui.html",
        "/v3/api-docs/**", "/webjars/**", "/favicon.ico",
        "/ws/detections"
    };

    @Bean
    public SecurityFilterChain securityFilterChain(...) {
        http
            .csrf(disable)                          // 无状态JWT，禁用CSRF
            .cors(corsConfig())                     // 允许跨域
            .sessionManagement(STATELESS)            // 无状态会话
            .authorizeHttpRequests(auth -> auth
                .requestMatchers(WHITE_LIST).permitAll()
                .anyRequest().authenticated()
            )
            // 过滤器顺序：DeviceApiKeyFilter → JwtFilter → UsernamePasswordFilter
            .addFilterBefore(deviceFilter, UsernamePasswordAuthenticationFilter.class)
            .addFilterBefore(jwtFilter, UsernamePasswordAuthenticationFilter.class)
            .exceptionHandling(ex -> ex
                .authenticationEntryPoint(authEntryPoint)    // 401
                .accessDeniedHandler(accessDeniedHandler));   // 403
        return http.build();
    }

    @Bean
    public PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder();  // BCrypt密码加密
    }
}
```

```java
// 用户列表（分页+模糊搜索）
public PageResult<UserVO> listUsers(int page, int size, String keyword) {
    Page<User> pageObj = new Page<>(page, size);
    LambdaQueryWrapper<User> wrapper = new LambdaQueryWrapper<>();
    wrapper.like(StringUtils.isNotBlank(keyword), User::getPhone, keyword)
           .or().like(StringUtils.isNotBlank(keyword), User::getUsername, keyword);
    wrapper.eq(User::getDeleted, false);  // 只查未删除
    Page<User> result = userMapper.selectPage(pageObj, wrapper);
    return PageResult.of(result.getRecords().stream()
        .map(u -> new UserVO(u)).collect(Collectors.toList()), result.getTotal());
}

public void updateUserStatus(Long userId, Integer status) {
```

#### 3.5 设备注册

```java
public DeviceVO registerDevice(Long userId, DeviceRegisterDTO dto) {
    // 1️⃣ 生成API Key（用于设备端认证）
    String apiKey = UUID.randomUUID().toString().replace("-", "").substring(0, 16);
    String apiSecret = generateApiSecret();

    // 2️⃣ 创建设备
    Device device = new Device();
    device.setDeviceCode(dto.getDeviceCode());  // IoTDA上的device_id
    device.setApiKey(SHA256.hash(apiKey));      // SHA256存储，不存明文
    device.setStatus("offline");
    deviceMapper.insert(device);

    // 3️⃣ 关联到果园
    OrchardDevice od = new OrchardDevice();
    od.setOrchardId(dto.getOrchardId());
    od.setDeviceId(device.getId());
    orchardDeviceMapper.insert(od);

    return DeviceVO(device, apiKey, apiSecret); // apiKey明文只返回一次
}
```

**设备端认证**（`DeviceApiKeyFilter`）：
```
设备请求 Header: X-API-Key: {apiKey} X-Timestamp: {时间戳}
                    │
                    ▼
① 查Device表获取SHA256(apiKey) → 匹配
② 校验时间戳是否在±5分钟内（防重放攻击）
③ 通过 → 设置设备上下文到SecurityContext
```

**IoTDA设备同步**（定时任务，每分钟执行）：
```java
@Scheduled(fixedDelay = 60000)
public void syncIotdaDevices() {
    JsonNode devices = iotdaClient.listDevices();  // 调用华为云IoTDA API
    for (JsonNode d : devices) {
        String deviceId = d.get("device_id").asText();
        Device local = deviceMapper.selectByDeviceCode(deviceId);
        if (local != null) {
            local.setStatus(d.get("status").asText());     // online/offline
            local.setShadowData(d.get("shadow").toString()); // 影子数据
            deviceMapper.updateById(local);
        }
    }
}
```

```java
private RiskAssessmentVO evaluateRule(AlertRule rule, EnvironmentData env,
                                       List<DiseaseDetection> detections) {
    RiskAssessmentVO result = new RiskAssessmentVO();
    result.setLevel(0);

    // 1️⃣ 环境因子评估
    if (env != null) {
        if (env.getTemp() > 35 && env.getHumidity() > 80) result.addFactor("高温高湿", 2);
        if (env.getRainfall() > 50) result.addFactor("强降水", 2);
        if (env.getTemp() < 5) result.addFactor("低温", 1);
    }

    // 2️⃣ 病害因子评估
    for (DiseaseDetection d : detections) {
        if (rule.getDiseaseCodes().contains(d.getTopClassCode())) {
            if (d.getConfidence() >= rule.getMinConfidence()) {
                result.addFactor(d.getTopClassName(),
                    d.getConfidence() >= 0.9 ? 3 : d.getConfidence() >= 0.8 ? 2 : 1);
            }
        }
    }

    // 3️⃣ 综合评分 = 所有因子分数之和 / 因子数量
    result.setScore(result.getFactors().isEmpty() ? 0 :
        result.getFactors().stream().mapToInt(Factor::getScore).sum() / result.getFactors().size());

    // 4️⃣ 映射到四级风险
    if (result.getScore() >= 3) result.setLevel(3);  // 高风险
    else if (result.getScore() >= 2) result.setLevel(2);
    else if (result.getScore() >= 1) result.setLevel(1);
    else result.setLevel(0);  // 无风险

    return result;
}
```

> **关键设计**: 环境因子+病害因子加权评分、四级风险(L0-L3)、5分钟周期评估

```java
public void processDocument(Long documentId) {
    KnowledgeDocument doc = documentMapper.selectById(documentId);
    doc.setStatus(1);  // PROCESSING
    documentMapper.updateById(doc);

    try {
        // 调用Python RAG服务处理文档

            new File(doc.getFileUrl()), "pdf", documentId);

        JsonNode root = objectMapper.readTree(result);
        if (root.has("error")) {
            if (root.get("error").asText().contains("not relevant")) {

                return;

            throw new BizException("处理失败: " + root.get("error"));
        }

        // 解析chunks并批量写入
        List<KnowledgeChunk> chunks = new ArrayList<>();
        JsonNode chunksNode = root.get("chunks");
        for (JsonNode node : chunksNode) {
            KnowledgeChunk chunk = new KnowledgeChunk();
            chunk.setDocumentId(documentId);
            chunk.setContent(node.get("content").asText());
            chunk.setContentHash(sha256(node.get("content").asText())); // SHA256去重
            chunk.setEmbedding(toJson(node.get("embedding"))); // 512维向量
            chunk.setChunkIndex(node.get("chunk_index").asInt());
            chunks.add(chunk);

        chunkMapper.batchInsert(chunks);

        doc.setChunkCount(chunks.size());
        doc.setStatus(2);  // COMPLETED
    } catch (Exception e) {
        doc.setStatus(3);  // FAILED
        doc.setFailReason(e.getMessage());
    }
```

```python
    text = extract_text_from_file(file)

                "潜叶蛾", "疮痂病", "日灼", "木虱", "蚜虫", "防治", "农药"]

    sentences = split_into_sentences(text)

    embeddings = embedding_model.encode([c["content"] for c in chunks])
```

#### 7.5 RAG问答全过程（Java编排）

```java
public RagResponse query(String question, String diseaseName,
                          EnvironmentData env, String model) {
    // Step 1️⃣: 策略路由
    String strategy = resolveStrategy(question, diseaseName);
    // → "diagnosis"（症状诊断）| "phenology"（物候）| "prevention"（防治方案，默认）

    // Step 2️⃣: Query增强
    String queryText = switch (strategy) {
        case "diagnosis"  -> question + " 症状 特征 诊断";
        case "phenology"  -> question + " 防治重点 农事";
        default           -> (diseaseName != null ? diseaseName + " " : "") +
                             question + " 防治方案";
    };

    // Step 3️⃣: 调用Python服务向量化 → 返回512维float[]
    float[] queryEmbedding = pythonRagClient.embed(queryText);

    // Step 4️⃣: pgvector混合检索（向量0.7 + 关键词0.3）
    List<ChunkResult> chunks = chunkSearchService.hybridSearch(
        queryEmbedding, queryText, 0.60, 5);

    if (chunks.isEmpty()) {
        return buildNoAnswer(question, "知识库中暂未找到相关信息...");
    }

    // Step 5️⃣: 构建Prompt → 调用LLM
    String context = chunks.stream()
        .map(c -> String.format("[%d] %s", c.getChunkIndex(), c.getContent()))
        .collect(Collectors.joining("\n---\n"));

    String prompt = String.format("""
        你是一个脐橙病虫害专家。请基于以下知识库内容回答用户问题。
        知识库内容：%s
        用户问题：%s
        请用农民能听懂的中文回答。
        """, context, question);

    // Step 6️⃣: 调用LLM（DeepSeek → 自动降级到Qwen）
    try {
        PythonRagClient.ChatResponse chatResp = pythonRagClient.chat(..., model);
        return new RagResponse(chatResp.getAnswer(), chunks);
    } catch (Exception e) {
        // 降级：直接返回检索到的原文片段
        return buildRawSearchResponse(question, chunks);
    }
}
```

**混合检索SQL（pgvector）：**
```sql
WITH vector_matches AS (
    SELECT c.id, c.content, c.chunk_index,
           1 - (c.embedding <=> #{queryEmbedding}::vector) AS vector_score
    FROM knowledge_chunk c
    JOIN knowledge_document d ON d.id = c.document_id
    WHERE d.status = 2  -- 已完成
      AND 1 - (c.embedding <=> #{queryEmbedding}) >= #{minScore}
),
keyword_matches AS (
    SELECT c.id, c.content, c.chunk_index,
           ts_rank(to_tsvector('simple', c.content),
                   plainto_tsquery('simple', #{keyword})) AS keyword_score
    FROM knowledge_chunk c
    JOIN knowledge_document d ON d.id = c.document_id
    WHERE d.status = 2
      AND to_tsvector('simple', c.content) @@ plainto_tsquery('simple', #{keyword})
)
-- 加权融合: 向量相似度(0.7) + 关键词BM25(0.3)
SELECT COALESCE(v.id, k.id) AS id,
       COALESCE(v.content, k.content) AS content,
       COALESCE(v.vector_score, 0) * 0.7 + COALESCE(k.keyword_score, 0) * 0.3 AS similarity
FROM vector_matches v
FULL JOIN keyword_matches k ON v.id = k.id
ORDER BY similarity DESC LIMIT 5
```

```java
public class SolarTermUtil {
    /**
     * 基于寿星公式计算指定年份的24节气日期
     * 纯Java算法，不依赖外部API
     */
    public List<SolarTerm> calculateSolarTerms(int year) {
        List<SolarTerm> terms = new ArrayList<>(24);
        for (int i = 0; i < 24; i++) {
            double century = (year - 1) / 100.0 + 1;
            double termDate = calculateTermDate(year, i, century);
            terms.add(new SolarTerm(TERM_NAMES[i], termDate));
        }
        return terms;
    }

    private double calculateTermDate(int year, int termIndex, double century) {
        // 寿星公式：基于天文算法，精度到日
        // 涉及：世纪参数修正 + 回归年长度修正 + 正弦震荡项
        double baseDate = getBaseDate(year, termIndex);
        double correction = getCorrection(century, termIndex);
        return baseDate + correction;
    }
}
```

**日期匹配算法（支持跨年区间）：**
```java
private boolean isInPeriod(int month, int day, FarmingCalendar cal) {
    int date = month * 100 + day;                      // 如 0501
    int start = cal.getStartMonth() * 100 + cal.getStartDay();
    int end = cal.getEndMonth() * 100 + cal.getEndDay();

    if (start <= end) {
        return date >= start && date <= end;            // 普通区间
    } else {
        return date >= start || date <= end;            // 跨年区间（11月→2月）
    }
}
```

```java
private String extractCoreAdvice(String answer) {
    // 只取第一句有效内容，且≤40字
    int firstPeriod = answer.indexOf("。");
    if (firstPeriod > 0) {
        String firstSentence = answer.substring(0, firstPeriod);
        // 如果第一句是"以下是根据知识库..."之类的引导语 → 取第二句
        if (countChineseChars(firstSentence) < 15) {
            int secondPeriod = answer.indexOf("。", firstPeriod + 1);
            if (secondPeriod > 0) firstSentence = answer.substring(0, secondPeriod);
        }
        return firstSentence.length() > 40 ?
            firstSentence.substring(0, 40) + "..." : firstSentence;
    }
    return answer.length() > 40 ? answer.substring(0, 40) + "..." : answer;
}
```

```java
    UserFeedback feedback = feedbackMapper.selectById(feedbackId);

    // 幂等保护：已审核不可重复审核
    if (feedback.getReviewStatus() != 0) throw BizException("该反馈已审核");

            break;
        case "reject":  // 驳回（必须提供原因）
            if (dto.getRejectReason() == null)
                throw BizException("驳回操作必须填写原因");
            feedback.setReviewStatus(3);
            feedback.setRejectReason(dto.getRejectReason());
            break;
    }

    feedback.setReviewedBy(reviewerId);
    feedback.setReviewedAt(LocalDateTime.now());
    feedbackMapper.updateById(feedback);

    // 如果采纳 → 创建知识文档入知识库
    if (dto.getAction().equals("accept")) {
        createKnowledgeDocumentFromFeedback(feedback);
```

## 八、关键技术亮点

| 序号 | 技术点 | 实现方式 |
|------|--------|---------|
| 1 | **双Token认证** | Access(2h) + Refresh(30d)，Redis主+PostgreSQL备，登出即失效 |
| 2 | **RAG知识库** | Java+Python混合架构，策略路由→pgvector混合检索(0.7向量+0.3BM25)→LLM生成 |
| 3 | **双LLM自动降级** | DeepSeek API为主，Qwen3-32B(昇腾NPU)为备，故障自动切换 |
| 4 | **机器学习风险预测** | scikit-learn Pipeline(50+维特征)+LLM分析报告 |
| 5 | **规则引擎** | 环境+病害因子加权评分，四级风险(L0-L3) |
| 6 | **多渠道推送** | WebSocket实时+微信模板+阿里云短信(L3)+网易邮件(L3) |
| 7 | **反馈闭环** | 用户反馈→AI审核→3态状态机→反哺知识库+导出训练集 |
| 8 | **农事日历** | 寿星公式纯算法计算节气+RAG个性化提醒+跨年日期支持+模板降级 |
| 9 | **IoTDA深度集成** | 设备注册/影子数据/命令下发/状态同步/API Key认证 |
| 10 | **数据缓冲** | Redis作为边缘设备上报缓冲层，批量刷盘防DB压力 |
| 11 | **文档防污染** | 四层漏斗：格式校验→关键词验证(≥2个)→语义相似度→人工审核 |
| 12 | **安全体系** | BCrypt密码、JWT签名、API Key SHA256、时间戳防重放、AOP审计日志 |
