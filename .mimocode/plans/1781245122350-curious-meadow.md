# 农事日历模块（M9）实现计划

## 背景

前端管理端和小程序端已有页面实现，等待后端接口。工具类 `SolarTermUtil` 和 `PhenologyPeriod` 已完成。数据库中 `farming_calendar` 表尚未创建。

## 实现步骤

### 1. 数据库建表

**文件**: `navel-orange-server/src/main/resources/db/schema.sql`（已有定义）

执行建表SQL + 插入7条物候期预置数据：

```sql
-- 建表（已在 schema.sql 中定义）
CREATE TABLE IF NOT EXISTS farming_calendar (...);

-- 插入7条物候期预置数据
INSERT INTO farming_calendar (phenology_name, solar_term, start_month, start_day, end_month, end_day, advice_content, disease_related, sort_order) VALUES
('春梢萌发期', '惊蛰', 2, 19, 3, 5, '加强水肥管理...', '["S12","S14"]', 1),
...（7条）
```

### 2. 创建后端代码

#### 2.1 实体类

**文件**: `navel-orange-server/src/main/java/com/citrus/calendar/entity/FarmingCalendar.java`

- 对应 `farming_calendar` 表
- 字段映射：id, orchardId, phenologyName, solarTerm, startMonth, startDay, endMonth, endDay, adviceContent, diseaseRelated, sortOrder, enabled, createdAt, updatedAt

#### 2.2 Mapper

**文件**: `navel-orange-server/src/main/java/com/citrus/calendar/mapper/FarmingCalendarMapper.java`

- 继承 BaseMapper<FarmingCalendar>
- 自定义方法：按日期查询当前生效的物候期

#### 2.3 Service

**文件**: `navel-orange-server/src/main/java/com/citrus/calendar/service/FarmingCalendarService.java`

**文件**: `navel-orange-server/src/main/java/com/citrus/calendar/service/impl/FarmingCalendarServiceImpl.java`

核心方法：
- `listCalendar(phenologyName)` → 日历列表（支持筛选）
- `createCalendar(dto)` → 创建
- `updateCalendar(id, dto)` → 更新
- `deleteCalendar(id)` → 删除
- `getCurrentReminder()` → 获取当前物候期提醒 + 下一个物候期

#### 2.4 Controller

**文件**: `navel-orange-server/src/main/java/com/citrus/calendar/controller/FarmingCalendarController.java`

5个接口：
- GET `/api/admin/calendar` → 日历列表
- POST `/api/admin/calendar` → 创建
- PUT `/api/admin/calendar/{id}` → 更新
- DELETE `/api/admin/calendar/{id}` → 删除
- GET `/api/miniapp/calendar/current` → 当前提醒

#### 2.5 DTO

**文件**: `navel-orange-server/src/main/java/com/citrus/calendar/dto/CalendarDTO.java`

- phenologyName, solarTerm, startMonth, startDay, endMonth, endDay, adviceContent, diseaseRelated

#### 2.6 VO

**文件**: `navel-orange-server/src/main/java/com/citrus/calendar/vo/CalendarVO.java`

**文件**: `navel-orange-server/src/main/java/com/citrus/calendar/vo/CurrentReminderVO.java`

- CalendarVO: 日历列表返回
- CurrentReminderVO: 当前提醒返回（含 current 和 upcoming）

### 3. 测试

**文件**: `navel-orange-server/src/test/java/com/citrus/calendar/service/FarmingCalendarServiceTest.java`

测试用例：
- 插入预置数据
- 查询日历列表
- 获取当前物候期提醒
- 验证"下一个物候期"计算逻辑
