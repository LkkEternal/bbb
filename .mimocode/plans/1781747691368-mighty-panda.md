# 脐橙病虫害监测系统 — UI 重新设计方案

## 设计方向

**用户选择**：
- 整体风格：清新自然绿色系
- 登录页：毛玻璃 + 动态粒子
- 看板：农业主题数据大屏（非科技风）

**设计核心理念**：将脐橙果园的自然美感融入管理后台 —— 温暖的柑橘色调、有机的圆润形态、呼吸感的留白。

---

## 一、色彩系统重构 —— "克制的绿"

**核心原则**：绿色不做大面积填充，只用在关键节点（active 指示器、成功状态、数据高亮）。大面积画布保持暖灰中性调。参考 Notion / Linear / Stripe Dashboard 的用色克制感。

### 1.1 品牌色板

```
画布底色:            #F8F9FA（极淡暖灰，不偏绿不偏蓝）
卡片色:              #FFFFFF
侧边栏底色:          #1B2028（深墨绿灰，非纯黑，微妙绿色 undertone）

主色（鼠尾草绿）:    #5B8C5A（低饱和、高级感的灰绿，非翠绿非荧光绿）
主色 hover:          #4A7A49（略深）
主色 light:          #E8F0E8（极淡绿，用于选中行背景、tag 底色）
主色 subtle:         #F2F7F2（几乎看不见的绿，用于卡片 hover 背景）

强调色（柑橘橙）:    #E8863A（温暖但不刺眼的橙，用于警告、CTA、数据亮点）
强调色 light:        #FFF4E8

深色文字:            #1A1C1E（近黑，非纯黑）
次要文字:            #5F6368（Google 灰，柔和）
占位文字:            #9AA0A6
边框:                #E5E7EB（极淡灰，几乎隐没）
分割线:              #F0F1F3
```

### 1.2 语义色（低饱和度，不刺眼）

```
成功:  #5B8C5A（与主色同源，不额外引入荧光绿）
警告:  #E8863A（橙）
危险:  #D64545（沉稳的红，非亮红）
信息:  #5F6368（灰）
```

### 1.3 病害等级色（从自然中取色）

```
健康:    #5B8C5A（鼠尾草绿 —— 叶片健康色）
缺素:    #D4A853（麦穗黄 —— 营养不足的黄）
真菌:    #E8863A（柑橘橙 —— 果实病变色）
细菌:    #D64545（石榴红 —— 严重病害色）
```

### 1.4 绿色使用禁区

- 禁止：绿色做按钮大面积填充（只用在 primary 按钮，且用 #5B8C5A 不用亮绿）
- 禁止：绿色做卡片背景色（只用 #F2F7F2 极淡绿做 hover 态）
- 禁止：绿色做侧边栏 active 背景的高饱和度版本
- 正确：绿色做 3px 左侧指示条、tag 边框、图标描边、数据高亮数字
- 正确：绿色大面积使用时必须降到 opacity 0.06-0.12

## 二、登录页重新设计

### 2.1 布局

全屏沉浸式，不分区。

### 2.2 背景层

- 底色：深墨绿 `#141E1B` 到 `#0B1210` 径向渐变（暗但有绿色 undertone，不纯黑）
- **动态粒子**：Canvas 绘制缓慢漂浮的圆形粒子，颜色用 `rgba(91,140,90,0.15)` 到 `rgba(232,134,58,0.1)`（绿色和橙色混合，模拟叶片和果实的光斑），数量 50-70 个，速度极慢（0.15-0.3px/帧），有轻微布朗运动，粒子大小 2-6px 随机
- 粒子之间不连线（连线是科技风，农业风用散落的光斑感）

### 2.3 登录卡片

- 居中，宽度 420px
- **毛玻璃效果**：`backdrop-filter: blur(20px); background: rgba(255,255,255,0.12);`
- 边框：`1px solid rgba(255,255,255,0.18)`
- 圆角：16px
- 阴影：`0 8px 32px rgba(0,0,0,0.3)`
- 内部 padding：48px 40px

### 2.4 卡片内容

- 顶部：Logo 图标（64x64）+ 系统名称（白色，24px，字重 600）
- 副标题：`rgba(255,255,255,0.6)` 14px
- 表单输入框：半透明背景 `rgba(255,255,255,0.08)`，白色文字，placeholder 用 `rgba(255,255,255,0.4)`，边框 `rgba(255,255,255,0.15)`，focus 时边框变为橙色 `#F2994A`
- 登录按钮：橙色渐变 `linear-gradient(135deg, #F2994A, #F2C94C)`，白色文字，圆角 8px，hover 时亮度提升
- Tab 切换：白色文字，active 下划线用橙色

## 三、侧边栏重新设计

### 3.1 整体

- 背景：`#1B2028`（深墨绿灰，微弱绿色 undertone，不是纯黑也不是亮绿）
- 不加渐变，纯色更高级
- 宽度：240px（展开）/ 72px（折叠）

### 3.2 Logo 区域

- 高度：72px
- 左侧：圆形 Logo（40x40）
- 右侧：系统名称（白色 `rgba(255,255,255,0.92)` 16px，字重 600）+ "管理后台"副标题（`rgba(255,255,255,0.35)` 12px）
- 底部：`1px solid rgba(255,255,255,0.06)` 分割线

### 3.3 菜单项

- 高度：44px
- 默认：`rgba(255,255,255,0.55)` 文字，图标同色
- Hover：背景 `rgba(255,255,255,0.04)`，文字 `rgba(255,255,255,0.85)`
- **Active**：左侧 3px 竖条 `#5B8C5A`（鼠尾草绿，不刺眼），背景 `rgba(91,140,90,0.08)`（极淡绿），文字 `#ffffff`，图标 `#5B8C5A`
- 绿色只出现在这 3px 的竖条上，大面积背景几乎看不出来是绿色

## 五、看板页面重新设计（农业主题数据大屏）

### 5.1 整体氛围

- 背景色：`#F8F9FA`（中性暖灰，不偏绿——大面积绿色会土）
- 页面顶部：一条 1px 高的渐变装饰线 `#5B8C5A` → `#E8863A`（绿到橙，极细，只做点缀）

### 5.2 统计卡片行（4 张）

**自定义卡片设计**：
- 背景：白色，圆角 12px
- 左侧：4px 宽的彩色竖条（鼠尾草绿、柑橘橙、蓝灰、红灰——不是纯色，是带灰度的）
- 阴影：`0 1px 3px rgba(0,0,0,0.04), 0 1px 2px rgba(0,0,0,0.06)`
- Hover：`transform: translateY(-2px)`，阴影加深
- 数字：32px 字重 700，颜色 `#1A1C1E`（近黑），不用彩色数字（彩色数字很土）
- 标签：13px `#5F6368`
- 右上角图标：40x40 圆形，背景色为对应颜色的极淡版 `opacity 0.08`
- **GSAP**：数字使用 CountUp 动画，卡片使用 stagger fadeInUp

### 5.3 图表区域

**趋势图（左 2/3）**：
- 自定义 ECharts 主题：绿色渐变区域图，橙色折线
- 网格线：极淡 `#E8E8E0`
- Tooltip：圆角 8px，阴影，无边框
- 背景：白色卡片，圆角 12px

**病害分布（右 1/3）**：
- 改为**环形图**，中心显示总数
- 颜色使用自然色系（绿、黄、橙、红、棕）
- 标签直接显示在环外侧

### 5.4 底部区域

**最新预警（左半）**：
- 每条预警用左侧彩色边框表示等级
- L3 红色、L2 橙色、L1 绿色
- 背景：白色，hover 时微上浮

**最新识别（右半）**：
- 图片缩略图改为圆角 8px
- 病害标签使用对应颜色的 pill 形状
- 整体更紧凑但不拥挤

### 5.5 农业元素融入

- 页面顶部装饰：一条 2px 高的渐变线 `#27AE60` → `#F2994A`（绿到橙，呼应脐橙从叶到果）
- 看板页面标题区域可加一个小的脐橙图标装饰
- 天气信息卡片（如有）使用天气图标 + 温度大字

## 六、通用组件样式覆盖

### 6.1 Element Plus 主题覆盖

通过 CSS 变量覆盖 Element Plus 默认主题：

```css
:root {
  --el-color-primary: #5B8C5A;
  --el-color-primary-light-3: #7FA87E;
  --el-color-primary-light-5: #A8C5A7;
  --el-color-primary-light-7: #D0E0D0;
  --el-color-primary-light-9: #EDF4ED;
  --el-color-primary-dark-2: #4A7A49;
  
  --el-color-warning: #E8863A;
  --el-color-danger: #D64545;
  --el-color-success: #5B8C5A;
  
  --el-border-radius-base: 8px;
  --el-border-radius-small: 6px;
  --el-border-radius-round: 20px;
  
  --el-box-shadow-light: 0 1px 3px rgba(0,0,0,0.04), 0 1px 2px rgba(0,0,0,0.06);
  --el-box-shadow: 0 4px 16px rgba(0,0,0,0.06);
  
  --el-bg-color: #FFFFFF;
  --el-bg-color-page: #F8F9FA;
  --el-text-color-primary: #1A1C1E;
  --el-text-color-regular: #5F6368;
  --el-border-color: #E5E7EB;
}
```

### 6.2 表格样式

- 表头：背景 `#F5F7F0`，字重 600，颜色 `#2D3436`
- 行 hover：背景 `#F0FAF4`（极淡绿）
- 边框：`#E8E8E0` 而非 `#EBEEF5`
- 圆角：外层容器 12px

### 6.3 按钮样式

- Primary：绿色渐变 `#27AE60` → `#2ECC71`
- 圆角：8px
- Hover：亮度提升 + 微上浮 `translateY(-1px)`

### 6.4 卡片样式

- 圆角：12px
- 边框：`1px solid #E8E8E0`
- 阴影：`0 2px 12px rgba(0,0,0,0.04)`
- Hover：`0 4px 20px rgba(0,0,0,0.08)`

## 七、GSAP 动画方案

| 场景 | 动画 |
|------|------|
| 页面切换 | FadeIn + translateY(10px)，0.3s ease |
| 统计卡片 | CountUp 数字滚动 + stagger fadeInUp |
| 图表容器 | Scale 从 0.95 到 1.0 + fadeIn |
| 侧边栏折叠 | 宽度过渡 0.3s cubic-bezier |
| 表格行 | Stagger fadeIn，每行延迟 30ms |
| 登录粒子 | Canvas requestAnimationFrame 循环 |
